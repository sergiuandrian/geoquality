# ISO 19157 mapping

geoqa tags each check result with an informative **ISO 19157** data-quality
element name (`dq_element` in JSON reports). This is for procurement language
and machine consumers — **not** a certified ISO 19157 conformance suite.

| geoqa check | DQ element |
|-------------|------------|
| `crs.*` | `DQ_AbsoluteExternalPositionalAccuracy` |
| `geometry.valid` / repair | `DQ_ConceptualConsistency` |
| `geometry.no_empty` / `no_missing` | `DQ_CompletenessOmission` |
| `duplicates.*` | `DQ_CompletenessCommission` |
| `attributes.required` / `not_null` / `max_null_fraction` | `DQ_CompletenessOmission` |
| `attributes.unique` | `DQ_ConceptualConsistency` |
| `attributes.domains` | `DQ_DomainConsistency` |
| `topology.*` | `DQ_TopologicalConsistency` |
| `schema.*` | `DQ_FormatConsistency` |
| `metadata.*` | `DQ_CompletenessOmission` |

Example JSON fragment:

```json
{
  "check": "topology.no_overlaps",
  "status": "fail",
  "dq_element": "DQ_TopologicalConsistency"
}
```
